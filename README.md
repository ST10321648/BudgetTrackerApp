## Description
Budgeta is a mobile budgeting application developed using Kotlin for Android. The purpose of this application is to help users track their daily income and expenses in a simple, efficient, and user-friendly way. It allows users to record financial transactions, view their spending history, and manage personal budgets effectively.
The application focuses on clean UI design, ease of use, and reliable local data storage.

## Key Features (Part 2)
- Key Features
- Add income and expense transactions
- Store transaction details (amount, description, date)
- Display a list of all recorded transactions
- Simple and clean financial overview
- Optional receipt/image indicator for transactions
- Local data persistence using a database (Room/SQLite if implemented)
- User-friendly and responsive Android UI

## How to Run the Project
- Clone the repository
- Open the project in Android Studio
- Allow Gradle to sync and download dependencies
- Connect an Android device or start an emulator
- Click Run to launch the application

## Application Overview
- Users can add new transactions with details
- Transactions are displayed in a scrollable list
- Data is stored locally and persists after app restart
- Clean and simple interface for easy navigation
